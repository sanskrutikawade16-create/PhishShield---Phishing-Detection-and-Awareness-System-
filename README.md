# PhishShield — Phishing Awareness Simulation

**PhishShield** is a GitHub Pages-ready academic prototype for demonstrating phishing and social-engineering awareness in a controlled environment.

## Developed By
- Sanskruti Kawade
- Sanskruti Kokane
- Rudra Patel

## Theme
Black / Cybersecurity

## Features
- Harmless simulated phishing email
- Fake training login page that collects **no credentials**
- Red-flag explanation
- Local-only demonstration counters using browser `localStorage`
- Awareness recommendations
- Responsive black cybersecurity UI
- Works as a static GitHub Pages website

## Project Objective
The project demonstrates how phishing messages use urgency, suspicious links, generic greetings and account threats to influence user behavior.

## Safety & Ethics
This project is intentionally designed for education:
- Never enter real passwords, OTPs, banking information or personal credentials.
- Obtain informed consent before testing with classmates.
- Use only a controlled academic environment.
- The site does not send data to a server.
- Results are stored only in the participant's browser for demonstration.

## Run Locally
Open `index.html` in a browser, or use a simple local server such as VS Code Live Server.

## Deploy on GitHub Pages
1. Create a GitHub repository, for example `phishshield-awareness`.
2. Upload all project files to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.
7. Your website will be available at:
   `https://YOUR-USERNAME.github.io/phishshield-awareness/`

## Suggested Academic Flow
1. Explain common phishing techniques.
2. Obtain informed consent from the test group.
3. Ask participants to inspect the simulated email.
4. Record only the anonymous action category.
5. Show the training lesson.
6. Discuss red flags and countermeasures.
7. Present the local results dashboard.
